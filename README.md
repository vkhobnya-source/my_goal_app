# Трекер целей и задач

У приложения есть регистрация и вход по электронной почте и паролю. Цели и задачи доступны только владельцу аккаунта; пользовательские данные хранятся в общей базе PostgreSQL.

## Запуск

1. Скопируйте `.env.example` в `.env` и задайте собственный `POSTGRES_PASSWORD`. Файл `.env` содержит настройки конкретного хоста и секреты, поэтому не добавляйте его в Git; для каждого хоста создавайте свой `.env`, используя `.env.example` как шаблон.
2. При необходимости укажите `OPENROUTER_API_KEY` для AI-предложений задач.
3. Запустите приложение: `docker compose up --build`.
4. Откройте `http://localhost` и создайте аккаунт.

Если порт `8000` уже занят, задайте свободный `BACKEND_PORT` в `.env` (например, `BACKEND_PORT=8001`). Это меняет только порт backend на хосте; frontend продолжит обращаться к нему через внутреннюю сеть Docker.

## Тесты

API-тесты запускаются командой `python -m pytest tests/test_api.py`. По умолчанию они используют изолированную SQLite-базу в памяти; при необходимости адрес тестовой базы можно задать через `TEST_DATABASE_URL`.

Браузерные E2E-тесты автоматически запускают отдельный тестовый стек: `python -m pytest tests/test_e2e.py tests/test_playwright.py`. По умолчанию браузер обращается к `http://localhost:8081`; порт можно изменить через `E2E_FRONTEND_PORT`, а URL — через `E2E_BASE_URL`. Тестовый backend использует временную SQLite-базу в отдельном контейнере и не подключается к рабочей базе. После тестов стек можно остановить командой `docker compose -f docker-compose.yml -f docker-compose.e2e.yml stop backend-e2e frontend-e2e`.

В production настройте HTTPS и задайте `COOKIE_SECURE=true`, чтобы браузер отправлял cookie сессии только по защищенному соединению. По умолчанию эта настройка выключена для локального HTTP-запуска.

При обновлении существующей базы таблицы пользователей и сессий создаются автоматически. Ранее созданные цели не привязаны к аккаунту и не отображаются пользователям; перед переносом старых данных назначьте им владельца после проверки и резервного копирования базы.
